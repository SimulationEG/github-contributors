🧩 LeetCode Solution: Reverse String (C#)

Problem 344 - Two Pointers In-Place Reversal

Approach: Two Pointers technique using left = 0 and right = s.Length - 1.
In-Place Modification: Swaps s[left] and s[right] in-place using a temporary scalar variable without allocating auxiliary array or calling built-in Array.Reverse methods.
Time Complexity: O(n) Space Complexity: O(1) 
public class Solution {
    public void ReverseString(char[] s) {
        int left = 0, right = s.Length - 1;
        while (left < right) {
            char temp = s[left];
            s[left] = s[right];
            s[right] = temp;
            left++;
            right--;
        }
    }
}
